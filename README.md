## 项目介绍

蛙蛙创作工作室是一款面向小说创作与蛙蛙平台投稿的 Windows 桌面工具，采用白绿色界面，将脑洞企划、章节生成、书稿管理、标题与简介优化、封面生成、投稿和收益查看集中在同一个客户端中。

可以从一个故事想法开始，也可以导入已有书稿进行自动包装与投稿。写作任务、完稿书库和投稿记录分别管理，支持批量操作、暂停与断点恢复。

**本仓库维护原版桌面客户端，目前已发布版本为 4.8.0。** 本页介绍均以原版功能为准，不包含正在重新设计的本地网页版本。

## 功能概览

| 模块 | 主要功能 |
| --- | --- |
| 脑洞企划 | 番茄风、飞卢风、七猫风、起点风及随机混合；书名与故事采用对应风格要求 |
| 自动写作 | 全书设定、章纲、正文生成、连续性检查、修订与续写；可设置精写章节数或全书精写 |
| 作品管理 | 写作进度、章节与字数查看；完稿留库；搜索、筛选、批量导出和删除 |
| 自动包装 | 内容分析、平台分类与标签匹配、书名评分、简介、征文入口及封面生成 |
| 自动投稿 | 书库直接投稿、任务进度、审核跟踪；按拒稿原因设置重投次数 |
| 多账号与笔名 | 独立保存登录会话，按账号关联笔名；自动为新书选择可用账号 |
| 投稿额度 | 每账号每日最多 3 次，可调低；失败计次，额度独立保存，等待次日恢复 |
| 提示词管理 | 集中编辑写作、脑洞、投稿与封面提示词；查看最近调用内容 |
| 收益查看 | 收益数据查询、笔名匹配与相关查询参数设置 |

自动流程依赖所配置的 AI 服务、平台登录状态及平台规则。异常结构、登录失效或需要核对的远端结果会进入等待或处理状态，不保证所有任务都能无人干预完成。

## 第一次使用

1. **配置 AI**：在设置中填写写作、投稿文本与图像接口，填写模型名称和密钥，按需测试。
2. **保存平台登录**：设置 → 平台账号，填写账号信息，打开浏览器手动登录，完成后点击保存登录。
3. **配置笔名**：为投稿账号关联可用笔名。
4. **创建或导入作品**：在创作工作台生成脑洞并加入写作任务，或在自动投稿中心导入已有书稿。
5. **检查进度与完稿**：生产记录查看写作状态；写完的作品进入书库。关闭自动投稿时，完稿仍然保留。
6. **开始投稿**：从书库点击投稿，或按导入时选择的执行方式运行；在投稿记录查看包装、上传及审核结果。

详细操作和故障处理见 [使用指南](docs/使用指南.md)。

## 原版的关键规则

### 多账号与每日额度

新书根据已保存登录、可用笔名、剩余额度与排队数量分配账号；已上传、待核对或重投稿件保留原账号。多账号的平台操作串行复用浏览器，AI 包装仍支持并行。

4.8.0 按每账号每日最多 **3 次正式投稿请求**计数，失败和超时同样占用额度，重投共用额度；补交章节请求也保守计次。标题、封面、稿件检查和审核查询不计次。

额度按北京时间日期保存，删除记录、退出账号或重启不会清零。网页或其他工具产生的投稿次数无法自动得知，平台返回当日额度已满时会停止该账号当天的请求。平台后续规则以平台实际要求为准。

### 书名与封面

书名优选目标为 **80 分**，吸引力权重为 45 分。原名不足时最多再生成两次；仍未达标则选择合法且未重名的最高分候选。空白、超长或同名书名不能直接采用。

封面仅保留 **基础提示词、画风提取、自定义附加** 三项。书名和笔名由绘图 AI 直接绘制，客户端不额外叠字，也不进行自动文字识别。

### 作品与记录

关闭完稿自动投稿，不影响完稿进入书库。移除投稿记录会保留投稿事实；本地删除不等于删除平台作品。对已有远端记录或结果不明的任务，应先核对状态再继续，避免重复创建投稿。

## 数据与备份

安装版用户数据保存在：

```text
%APPDATA%\wawa-unified-studio
```

源码版本与安装包备份不能代替个人作品备份。升级或回档前，先退出软件，再复制整个用户数据目录。

该目录可能包含 API 密钥、登录会话、账号资料和书稿，**不要提交到仓库或附在公开问题报告中**。本仓库用于保存源码与版本发布资料，不包含个人运行数据。

完整恢复方法见 [版本回档](版本回档.md)。

## 从源码运行

环境：Windows x64、Node.js 22，以及项目的 Python 嵌入式运行环境。

1. 下载对应版本源码。
2. 将该版本 Release 的 Python 运行环境压缩包解压到项目根目录，确认存在 `runtime/python.exe`。
3. 在项目目录执行：

```powershell
npm ci
npm test
.\runtime\python.exe -X utf8 engine/test_app.py
npm start
```

构建安装包：

```powershell
npm run dist -- --publish never
```

产物在 `dist` 目录。开发调试建议通过 `WAWAWA_DATA_DIR` 指定独立数据目录，避免使用日常账号和书稿。

### 主要目录

| 路径 | 用途 |
| --- | --- |
| `main.mjs` / `preload.cjs` | Electron 主进程与界面通信 |
| `renderer/` | 桌面界面 |
| `engine/` / `writer-client.mjs` | Python 写作引擎与进程通信 |
| `automation-engine.mjs` | 投稿任务调度与阶段处理 |
| `packaging-ai.mjs` / `prompt-catalog.mjs` | AI 包装与提示词 |
| `core.mjs` | 蛙蛙平台自动化 |
| `account-profiles.mjs` / `submission-quota.mjs` | 账号会话隔离与额度记录 |
| `tests/` | 回归测试 |
| `.github/workflows/` | 历史版本构建与发布 |
