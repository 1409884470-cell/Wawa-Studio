# 4.8.0 多账号自动分配与每日投稿额度

- 在设置 → 平台账号逐个填写手机号、打开浏览器完成登录、保存登录。可给账号添加备注。切换账号保留各自的登录状态；退出或删除账号仅清除该账号的会话。
- 新导入的投稿书籍自动分配给已登录且有可用笔名的账号，按剩余额度及排队数量分配。已有上传、待核对或重投稿件保留原账号；登录失效只阻塞该账号的任务。正文写作与离线包装不要求平台登录。
- 每号每日最多 3 次正式投稿请求，设置可调低为 1 或 2。失败、超时均占次数，重投共用额度；为保守遵守新规则，补交章节请求也计次。生成标题、封面、检查稿件及审核查询不计次。
- 当日额度耗尽显示“等待次日”，按北京时间零点恢复资格，运行中的软件每分钟检查等待任务。暂停或关闭软件不会自动继续；仍遵循原有的启动恢复设置。
- 额度独立持久保存，删除投稿记录、退出账号或重启不会清零。旧版记录迁移按已有请求记录保守计入；其他软件或网页投稿无法自动得知，平台提示当日额度已满时会停止该账号当天的请求。
- 多账号站点操作串行复用一个浏览器，AI 包装仍使用原有并行设置；新书优先于失败重投。

## 4.7.0 手动登录与直接投稿

- 设置 → 平台账号：填写手机号，打开浏览器登录，完成后保存登录。后台只复用会话，失效后暂停，不再在隐藏浏览器等待手动登录。
- 保存登录失败会明确报错；保存成功后恢复等待登录的任务。
- 书库“投稿”直接启动所选书；其他暂停作品不启动。导入并执行不再需要二次点击继续队列。
- 精简页头说明、重复跳转卡片和重复并发设置，保留必要错误与结果提示。

## 4.6.1 书库与投稿状态修复

- 完稿书库独立于投稿队列：关闭自动投稿后，完稿仍显示为“已完稿 · 未投稿”。
- 移除投稿记录保留投稿事实、笔名及正文；书库可恢复记录，不创建重复投稿。
- 单本、批量转入投稿中心；沿用现有队列暂停状态，暂停时需在投稿中心继续。
- 草稿上传、提交确认、待核对分别显示；已归档完稿和队列旧状态自动兼容。
- 从书库删除作品与移除投稿记录分开处理。本地删除仍保留回收副本。

# 蛙蛙创作工作室 4.6.0

安装“蛙蛙创作工作室-4.6.0-安装包.exe”。软件自带运行环境，平台自动化需本机 Chrome 或 Edge。

## 工作流程

1. 设置 AI 接口、平台账号和笔名库。
2. 在创作工作台生成脑洞，可选择番茄风、飞卢风、七猫风、起点风或随机混合。书名与剧情使用同一风格要求；企划可编辑。
3. 加入写作任务，查看状态、章节进度和字数。支持搜索、筛选、批量继续、暂停、收尾和删除。
4. 完稿自动在作品书库显示，从写作列表移出。书库支持搜索、投稿状态筛选、批量导出和删除。未完稿可在写作任务中阅读，不混入书库。
5. 全流程开启且允许完稿自动投稿时，使用自动投稿中心保存的默认方案。投稿记录中查看包装、上传和审核进度。

## 提示词

设置 → 提示词设置中统一编辑写作、脑洞书名、投稿与封面提示词。

- 保存本项：用于后续请求，不自动重做已缓存结果。
- 保存并更新待投稿作品：让未上传且不在执行中的任务重做对应步骤，保留不相关结果。正在执行、已上传或有远端核对记录的任务跳过，界面报告数量。队列暂停时等待继续；运行时按队列执行。
- 查看最近调用：显示该项最近使用的文本与时间。封面基础模板、排版、明暗、自定义补充显示最近完整图像提示词；拒稿补充显示最近正文修订请求。未调用过则显示尚未调用。
- 写作提示词修改用于下一次对应请求；不自动重写已经保存的章节。并非所有提示词每本书都会调用，例如续写、拒稿修订只在相应条件下使用。
- 旧版未修改的默认提示词自动迁移，自定义内容保留。若自定义提示词相互冲突，可恢复对应默认后保存。变量及 JSON 输出格式需保留。

## 书名与封面

书名优选目标为80分：吸引力45、内容贴合20、易读顺口15、辨识度10、题材风格10。原名不足80分时最多再生成两次并评分，达标提前采用；均不足80分则选择原名和候选中最高分的合法、未重名书名。空白、超过30字或同名的候选不能使用。网络失败会保留已完成的评分。

封面只保留三项：基础提示词、画风提取、自定义附加，均在设置 → 提示词设置 → 封面中编辑。基础提示词包含书名、笔名、画风和本书剧情；画风只调用一次文本 AI；自定义附加直接拼接。移除剧情视觉补充、独立构图、明暗、旧前缀与负面词，以及包装方案内的封面偏好，旧值不再参与生成。

完整书名和笔名继续由绘图 AI 画出；基础模板强化文字要求，保存时自动补回遗漏的书名、笔名和画风变量，并在编辑框显示。没有客户端叠字或自动文字识别，画字质量仍取决于所用图像模型。

升级不会改动已上传作品。未上传且仍在处理中、已有旧提示词缓存的任务会回到封面提示词步骤；继续队列后按新三项设置重做封面。已完成的本地包装可使用“按新规则重做封面”。

## 其他设置

- 精写章节数与全书精写在写作参数中设置，作用于后续章节。
- 投稿包装并行1—6本，同账号的平台写入依次执行。
- 质量、非质量与原因不明的重投次数分别设置，0为不重投。
- 库外类目按对应大类归入脑洞分类；标签从系统库匹配。
- 明确格式杂项自动清理，纯关键词命中不阻断正常剧情；结构异常仍提示核对。
- 删除是本地操作，书稿保留回收副本，不删除平台作品。

升级不清除已有账号、密钥、笔名和作品。生产数据保存在本机用户目录，安装包不包含开发或测试账号。
