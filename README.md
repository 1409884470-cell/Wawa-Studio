# 蛙蛙创作工作室 4.5.1

安装“蛙蛙创作工作室-4.5.1-安装包.exe”。软件自带运行环境，平台自动化需本机 Chrome 或 Edge。

## 工作流程

1. 设置 AI 接口、平台账号和笔名库。
2. 在创作工作台生成脑洞，可选择番茄风、飞卢风、七猫风、起点风或随机混合。书名与剧情使用同一风格要求；企划可编辑。
3. 加入写作任务，查看状态、章节进度和字数。支持搜索、筛选、批量继续、暂停、收尾和删除。
4. 完稿自动在作品书库显示，从写作列表移出。书库支持搜索、投稿状态筛选、批量导出和删除。未完稿可在写作任务中阅读，不混入书库。
5. 全流程开启且允许完稿自动投稿时，使用自动投稿中心保存的默认方案。投稿记录中查看包装、上传和审核进度。

## 提示词

设置 → 提示词设置中统一编辑写作、脑洞书名、投稿与封面提示词。

- 保存本项：用于后续请求，不自动重做已缓存结果。
- 保存并更新待投稿作品：让未上传且不在执行中的任务重做对应步骤，保留不相关结果。正在执行、已上传或有远端核对记录的任务跳过，界面报告数量。队列暂停时等待继续；运行时按队列执行。
- 查看最近调用：显示该项最近使用的文本与时间。封面基础模板、排版、明暗、自定义补充显示最近完整图像提示词；拒稿补充显示最近正文修订请求。未调用过则显示尚未调用。
- 写作提示词修改用于下一次对应请求；不自动重写已经保存的章节。并非所有提示词每本书都会调用，例如续写、拒稿修订只在相应条件下使用。
- 旧版未修改的默认提示词自动迁移，自定义内容保留。若自定义提示词相互冲突，可恢复对应默认后保存。变量及 JSON 输出格式需保留。

## 书名与封面

书名优选目标为80分：吸引力45、内容贴合20、易读顺口15、辨识度10、题材风格10。原名不足80分时最多再生成两次并评分，达标提前采用；均不足80分则选择原名和候选中最高分的合法、未重名书名。空白、超过30字或同名的候选不能使用。网络失败会保留已完成的评分。

封面按基础信息、可编辑排版要求、本书剧情画面、明暗要求、自定义补充拼接。新版不再硬编码人物80%或统一七猫画风。画面与书名效果由实际图像模型决定。已生成但未上传的作品可在投稿详情中“按新规则重做封面”，将重新调用接口；已上传封面不自动覆盖。

重新包装保留已绑定笔名；各包装步骤自动恢复或分配笔名。封面署名随本地笔名变更重做，已上传作品保留原署名。无符合条件或有额度的笔名时等待补充。

## 其他设置

- 精写章节数与全书精写在写作参数中设置，作用于后续章节。
- 投稿包装并行1—6本，同账号的平台写入依次执行。
- 质量、非质量与原因不明的重投次数分别设置，0为不重投。
- 库外类目按对应大类归入脑洞分类；标签从系统库匹配。
- 明确格式杂项自动清理，纯关键词命中不阻断正常剧情；结构异常仍提示核对。
- 删除是本地操作，书稿保留回收副本，不删除平台作品。

升级不清除已有账号、密钥、笔名和作品。生产数据保存在本机用户目录，安装包不包含开发或测试账号。
